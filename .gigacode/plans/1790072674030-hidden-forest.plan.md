# План: Реализация async методов FastCacheStandaloneClient

## Контекст

- `FastCacheStandaloneClient` в `standalone_client.cpp` уже имеет реализацию конструкторов, `shutdown()`, `RunCompletionQueue()`
- В `common/include/utils.hxx` есть `RpcCallData` и `StreamCallData` шаблоны
- В `standalone_client.hxx` есть `SendAsyncRequest` и `SendAsyncStreamRequest` шаблоны
- Все ~58 методов уже объявлены в header как `std::future<T>` — нужно реализовать их body

## Паттерн для unary RPC

```cpp
std::future<ResultType> FastCacheStandaloneClient::methodName(const Key& key, ...) {
    // 1. Build request proto
    hurricache::RequestProto request;
    request.set_key(buildKey(key, hint, clientId));
    // ... fill fields ...
    
    // 2. Send async request via template
    return SendAsyncRequest<hurricache::RequestProto, hurricache::ResponseProto, ResultType>(
        request, timeout,
        &hurricache::HurriCacheGrpcService::Stub::AsyncMethodName,
        // transformer (optional):
        [](hurricache::ResponseProto& resp) -> ResultType {
            return extract_result(resp);
        }
    );
}
```

## Паттерн для streaming RPC

```cpp
std::future<ResultType> FastCacheStandaloneClient::streamMethodName(...) {
    hurricache::GetRequest request;
    request.set_key(buildKey(key, hint, clientId));
    
    return SendAsyncStreamRequest<hurricache::GetRequest, hurricache::BatchValueResponse, ResultType>(
        request, timeout,
        &hurricache::HurriCacheGrpcService::Stub::PrepareAsyncMethodName,
        // accumulator:
        [](ResultType& result, hurricache::BatchValueResponse& chunk) {
            // accumulate chunks
        }
    );
}
```

## Реализация по частям

### Часть 1: Helpers + TTL + Key-Value (~10 методов)

**Helpers (private):**
- `buildKey(const Key&, const KeyHint&, int32_t)` — заполняет `hurricache::Key` proto
- `buildGetRequest(const Key&, const KeyHint&, int32_t)` — заполняет `hurricache::GetRequest`
- `buildValue(const Value&, std::chrono::milliseconds, int32_t)` — заполняет `hurricache::Value` proto с compression

**TTL:**
- `setTtl` → `AsyncSetTtl` → `BoolResponse::value()`
- `getTtl` → `AsyncGetTtl` → `TtlResponse::ttl() - now`

**Key-Value:**
- `getAndDeleteValue` → `AsyncGetAndDeleteValue` → `ValueResponse` → decompress
- `createKeyValue` → `AsyncCreateKeyValue` → `KeyHintResponse` → extract hashes
- `getValue` → `AsyncGetValue` → `ValueResponse` → decompress
- `updateKeyValue` → `AsyncUpdateValue` → `UpdateValueResponse` → decompress
- `existKey` → `AsyncExistKey` → `BoolResponse::value()`
- `remove` → `AsyncRemove` → `BoolResponse::value()`

## Compression helpers

В `buildValue` использовать `compressIfNeeded` из `common/include/compression.hxx`:
```cpp
::hurricache::Value buildValue(const Value& value, std::chrono::milliseconds ttl, int32_t clientId) {
    ::hurricache::Value proto_value;
    auto* payload = proto_value.mutable_value();
    payload->set_size(value.size);
    payload->mutable_payload()->assign(value.data, value.size);
    
    if (value.size > defaultCompressionThreshold_) {
        // compress
        proto_value.set_compression_info_enabled(true);
        proto_value.mutable_compression_info()->set_rawsize(value.size);
    }
    
    if (ttl.count() > 0) {
        proto_value.set_ttl(std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::system_clock::now().time_since_epoch()).count() + ttl.count());
    }
    return proto_value;
}
```
